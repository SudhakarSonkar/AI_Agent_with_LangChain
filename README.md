# 📝 Todoist Assistant with Gemini (LangChain)

This project is a **chat-based assistant** built using [LangChain](https://www.langchain.com/), [Google Gemini](https://ai.google.dev/), and [Todoist API](https://developer.todoist.com/).  
It allows you to:

- 💬 Chat with an AI assistant (Gemini)  
- ✅ Add tasks to your Todoist account  
- 📋 View existing tasks in a clean list  
- 🔄 Maintain chat history for context  

---

## 🚀 Features

- **General Conversations** – Ask questions like *"What is a banana?"*  
- **Task Management** – Add tasks with natural language (*"Add a task to buy milk"*)  
- **View Tasks** – See all current tasks from your Todoist list, filtered and clean  
- **Chat Memory** – Keeps conversation history so context isn’t lost
