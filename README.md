# 📝 Todoist Assistant with Gemini (LangChain)

A **chat-based assistant** that can:
- 💬 Hold normal conversations (general Q&A)
- ✅ Add tasks to your Todoist
- 📋 Show your existing tasks in a clean list
- 🔄 Keep lightweight chat history for context

Built with **LangChain**, **Google Gemini**, and **Todoist API**.

---

## ✨ Features

- Natural chat + task management via tools  
- Clean task rendering (filters out Todoist’s default “template” links)  
- Minimal logs (no noisy “Entering AgentExecutor chain…” lines)  
- Simple in-memory history with a configurable cap
